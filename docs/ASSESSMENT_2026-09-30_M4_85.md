# Morva Technical Assessment — 2026-09-30 — M4.85

## M4.85 — Repository-wide historical integrity contract

M4.85 adds an executable dependency contract covering the M4.77–M4.81 verification chain.

### Implemented

- AST-checked dependency edges for the runtime and persistence layers.
- Forward-dependency rejection for future M4 layers.
- Test-to-layer coverage checks for the expected runtime/persistence symbols.
- Continued prohibition of local SHA-256 implementations in the guarded runtimes.
- Dedicated CI for the repository-wide integrity contract.

### Boundary

No persistence schema, API contract, fingerprint payload, blocker code, provider execution, credentials, payment mutation, legal-rate inference or production authorization changes are introduced.

# Morva Technical Assessment — 2026-10-01 — M4.85

## M4.85 — Historical integrity timestamp primitive guard

M4.85 adds a structural regression contract over the M4.77/M4.78 historical-integrity runtimes.

### Implemented
- AST-based validation requires M4.77/M4.78 to import `canonical_utc_timestamp` from the shared primitive.
- The guard rejects direct timezone-UTC imports/usages in those runtimes.
- The guard rejects local `datetime.isoformat()` timestamp serialization.
- A dedicated CI gate runs Ruff and focused pytest coverage.

- M4.84 guard CI is green on `4960757a31dac247a433d945377d1b3a34aa53f0`.
- M4.85 is built directly from that verified M4.84 HEAD.
- No M4.85 persistence, API, fingerprint, blocker or production-authority changes are introduced.

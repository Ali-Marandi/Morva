# Morva Technical Assessment — 2026-09-29 — M4.83

## M4.83 — M4.80 canonical integrity primitive adoption

M4.83 removes the remaining local SHA-256 serialization implementation from the M4.80 verifier and binds it to the shared canonical integrity primitive introduced by M4.82.

### Implemented
- M4.80 verification fingerprints now call the shared canonical SHA-256 JSON primitive.
- Existing M4.80 fingerprint payload fields and ordering semantics remain unchanged.
- Regression coverage locks the M4.80 fingerprint calculation to the shared primitive.
- Dedicated CI validates Ruff and focused pytest coverage.

### Boundary
This is a semantics-preserving integrity refactor. No provider execution, credentials, payment mutation or production authorization is introduced.

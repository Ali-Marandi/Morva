# M3.80 — Integration Contract Manifest

M3.80 records the internal contract shape for the six external integration boundaries:
SINA, accounting, treasury, bank, tax and insurance.

The manifest binds the repository/candidate SHA, payload schema version, canonical adapter
set, required operation names, correlation/idempotency requirements and a deterministic
fingerprint.

It is not an official provider contract and does not authorize external network calls.

# Morva Legal Catalog

این سند فهرست کنترل‌شده منابع حقوقی مورد نیاز برای موتور قوانین مرواست. هیچ مورد `review_required` نباید در محیط تولید فعال شود.

## وضعیت‌ها

- `candidate`: منبع/قاعده برای تحلیل اولیه ثبت شده است.
- `review_required`: نیازمند بررسی متن منبع اولیه، تاریخ اثر و تأیید کارشناس مالی/حقوقی.
- `approved`: متن منبع و دامنه اثر تأیید شده و تست بازگشتی دارد.
- `retired`: دیگر نباید برای محاسبات جدید انتخاب شود، ولی برای بازسازی تاریخی حفظ می‌شود.

## قواعد کنترل انتشار

هر Rule تولیدی باید حداقل این اطلاعات را داشته باشد:

- منبع حقوقی و مرجع صادرکننده
- شماره/ماده/بند در صورت وجود
- تاریخ تصویب و تاریخ اثر
- تاریخ انقضا یا وضعیت جاری
- دامنه مشمولان
- فرمول یا شرط احراز
- نحوه برخورد با مالیات، بیمه و بازنشستگی
- نسخه Rule
- نام و زمان بازبین
- تست رگرسیون
- نمونه محاسبه مستقل
- hash ورودی/خروجی نمونه

## یادداشت مهم

مروا از این فهرست برای traceability استفاده می‌کند؛ ثبت یک منبع در اینجا به‌معنای تأیید اجرایی آن نیست. تغییرات مقررات باید با Rule Pack جدید منتشر شوند و تاریخچه نسخه قبلی حفظ شود.

# M4.6 — Adapter Contract Evidence Bridge

M4.6 binds the existing provider-neutral official-adapter evidence registry to an M4.1 authoritative `adapter_contract` evidence item.

The bridge requires exact contract-source URI and SHA-256 equality and rejects missing, unaccepted, future-dated, expired or not-yet-effective authoritative evidence.

Repository/candidate-SHA lineage remains governed by the existing M3.75 adapter evidence contract; M4.6 does not activate providers or use credentials.

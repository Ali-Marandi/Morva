# M4.2 — Evidence Closure Matrix

M4.2 turns the M4.1 evidence registry into an explicit, deterministic closure assessment.

## Canonical closure roles

The matrix maps the twelve existing production-certification roles to provider-neutral evidence source types:

- legal approval → legal rule
- finance approval → finance approval
- security assessment → security assessment
- operations approval → operations approval
- authoritative master data → master data
- official adapters → adapter contract
- reconciliation evidence → reconciliation
- disaster recovery exercise → DR report
- load validation → load validation
- release certification → release certification
- publication evidence → publication
- deployment validation → deployment validation

A role is satisfied only by accepted evidence that is currently effective, approved no later than the assessment time, and not expired.

## Safety boundary

M4.2 does not create or assume real ministry data, legal rates, payroll records, credentials, provider endpoints or production approvals. It evaluates only what has actually been supplied to the M4.1 registry.

The resulting assessment is a software readiness measurement, not production certification.
